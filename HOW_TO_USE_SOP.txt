I've created your Admin Standard Operating Procedures in **3 formats**:

- **File:** `sop.pdf` (will be created after you print from HTML)
- **Best For:** Distribution, sharing with team, portable viewing

## 🎯 Most Important Commands to Remember

### Command 1: Broadcasting Promotions
```
Location: PROMOTIONS topic
Command: /promo
Text: Your promotion message
Result: Broadcast to all known users
```

### Command 2: Send User DMs
```
Location: ADMIN_USER_MSGS topic
Command: /msguser USER_ID Message text
Result: Direct message sent to user
```

### Command 3: Create Game
```
Location: MANAGE_GAMES topic
Format: GAME | id=GameX | name=Game Name | status=ACTIVE | download_url=https://example.com/app.apk
Result: New game available to users
```

### Command 4: Add Account
```
Location: ACCOUNT_INVENTORY topic
Format: ACCOUNT | game=GameX | username=user | password=pass | status=AVAILABLE
Result: Account ready for FIFO assignment
```

### Command 5: Set/Update Game Download Link
```
Location: MANAGE_GAMES topic
Format: GAME | id=GameX | name=Game Name | status=ACTIVE | download_url=https://example.com/app.apk
Result: Users can access the link from 📥 Download Game and see it at top of main menu for selected game
```

### User Menu Behavior (Download Feature)
```
1. User selects a game
2. Main menu shows selected game + current download link at the top
3. User taps 📥 Download Game
4. Bot shows the game's download link and an open-link button
5. If download_url is not set, bot shows "Download link is not set yet"
```

## ❓ Common Questions

### Q: Where do I go to approve load requests?
**A:** LOAD_APPROVALS topic. You'll see payment screenshots with ✅ Approve / ❌ Reject buttons.

### Q: How do I find a user's ID?
**A:** It appears in approval request messages in LOAD_APPROVALS or WITHDRAW_APPROVALS topics.

### Q: What happens if I reject a request?
**A:** Bot asks for your rejection reason in the same topic. Type the reason, and it's sent to the user.

### Q: Can I delete messages?
**A:** NO. Never delete messages. They're part of the audit trail. Only edit if explicitly stated.

### Q: How do I know if the bot is running?
**A:** Check SYSTEM_BACKUPS topic. Should see a pinned message with recent timestamp. Also check server console logs.

### Q: What if I run out of accounts?
**A:** Go to ACCOUNT_INVENTORY topic and add more with the ACCOUNT format.

### Q: How do I add game download link for users?
**A:** In MANAGE_GAMES topic, post/update the GAME line with `download_url=https://...`.
Users can then open it from the 📥 Download Game menu for their selected game.

### Q: Can users see the admin topics?
**A:** NO. Only admins in the supergroup can see these topics. Users only see their private chat with the bot.
